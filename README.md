# Propuestas web · Clínica Villaespai

5 propuestas de diseño para Clínica Villaespai (Vilamarxant, Valencia). Abre `index.html` (es el menú selector) con doble clic. No hace falta compilar nada; sí hace falta internet porque Tailwind, Google Fonts, Lucide, las imágenes de Unsplash y Google Maps se cargan por CDN.

| Carpeta | Estilo |
|---|---|
| opcion-1-minimalista | Clínico minimalista (Plus Jakarta Sans, blanco/azul médico) |
| opcion-2-calida | Bienestar orgánico (Lora + Nunito Sans, tierra/oliva/terracota) |
| opcion-3-moderna-tech | Bento grid tecnológico (Space Grotesk, marino/cian/menta) |
| opcion-4-editorial | Revista de salud (Fraunces + DM Sans, crema/verde bosque, tarjetas que giran) |
| opcion-5-dinamica | Familiar y activa (Outfit, cielo/coral, filtro + asistente de cita en 3 pasos) |

En las cinco: cabecera fija con botón «Pedir cita» que abre un modal y prepara el mensaje de WhatsApp, enlaces tel:/wa.me/mailto, horario, mapa, Instagram/Facebook y diseño responsive.
